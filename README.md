# 豆格工坊

一个可以自己运行的拼豆全栈平台。前端使用原生 JavaScript 和 Canvas，服务端使用 Node.js HTTP 和 SQLite。参考 [xiaoana.cn](https://xiaoana.cn/) 的公开产品流程，界面、示例图和代码独立实现。

## 启动

需要 Node.js 24 或更新版本。在项目根目录运行：

```powershell
npm ci
npm start
```

打开 [本地创作台](http://127.0.0.1:3001/)。用 `npm run dev` 启用服务端文件监视，`npm test` 运行图纸算法、账号、库存、积分与卡密测试。

## 创作与运营

- **创作台**支持照片、空白画板、文字、链接和二维码图片。图纸宽度和颜色合并支持滑杆及手动输入，可独立开启颜色上限。图纸编辑器有色号搜索、去边缘背景、颜色替换、自定义色板和用豆清单，支持 PNG、CSV、JSON、视频与浏览器打印 PDF。
- **我的作品**会把本地草稿保存到 IndexedDB。上传图片在浏览器处理，云端只存图纸网格和色板。登录后可以跨设备编辑云端作品。
- **图纸库**支持题材筛选、搜索、排行、收藏、点赞、留言和积分获取。注册时送 20 积分。付费图纸首次获取时扣分，积分进入发布者账户。
- **我的工坊**包含库存、出入库记录、创作者数据、卡密激活和账号设置。注册时请保存账号恢复码。支持使用已绑定的卡密和账号密码登录。

## 配置管理员与外部服务

将 [配置示例](.env.example) 复制为 `.env`，修改后重启。管理员可以生成卡密、处理反馈，并推荐或下架社区图纸。

1. 填写 `ADMIN_ACCOUNT` 和随机生成的 `ADMIN_BOOTSTRAP_SECRET`。
2. 打开 [管理员注册入口](http://127.0.0.1:3000/me?setup=1)，点「登录 / 注册 → 注册」，使用配置中的账号和注册密钥建立管理员。注册完成后可移除注册密钥。
3. 使用同一账号登录，进入「我的 → 平台管理」。也可直接打开 [平台管理](http://127.0.0.1:3001/admin)。

| 功能 | 配置与运行方式 |
| --- | --- |
| 创作卡密 | 默认必须激活有效卡密才能进入编辑器、生成、编辑或发布图纸。管理员在「平台管理」中生成卡密。可用 `CARD_SHOP_URL` 指向运营方的购卡渠道。 |
| 远程图纸库 | 设置 `REMOTE_LIBRARY_MANIFEST_URL` 指向公开的 S3 图纸目录 JSON。当前目录会显示远程预览图和原图链接，远程素材不会写入本地数据库。 |
| 账号 | 使用用户名和密码注册、登录。用户名为 2–32 位字母、数字、下划线或短横线。找回密码使用注册后保存的恢复码。 |
| 社群与客服 | 可配置 `COMMUNITY_URL` 与 `SUPPORT_EMAIL`。站内反馈可在后台读取和结案。 |

部署时将 HTTPS 反向代理指向 Node 进程，并设置 `PUBLIC_ORIGIN` 为对外域名。为 `DB_FILE` 或默认 `data/` 目录建立持久存储与备份。可使用 SQLite 的在线备份能力，或在停服后备份数据库与 SQLite 的辅助文件。

## 色板来源

采用 [HansBug/pindou-color-data 的 MIT 数据](https://github.com/HansBug/pindou-color-data/tree/178dafbc9e77d3de556550dbd058270200129186)。使用可识别的色号，收录 MARD 291、COCO 291、漫漫 278、盼盼 285、咪小窝 286 色。24 到 144 色是根据色差选出的子集，MARD 221 使用标准组别。附 [色卡许可](PALETTE-LICENSE.txt)。颜色为屏幕参考值。
